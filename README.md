# D’THIRD portfolio

An editorial portfolio for an independent videographer, built with the Next.js App Router and ready to deploy on Vercel.

## Run locally

```sh
npm install
npm run dev
```

Open `http://localhost:3000`. To create and run a production build, use `npm run build` and `npm start`.

## Routes and search metadata

- `/` is the portfolio home page.
- `/credentials` presents selected portfolio work and the certificate archive.
- `/robots.txt` and `/sitemap.xml` are generated by the App Router.
- Unknown paths use the custom branded 404 page.
- The root layout includes page metadata, social cards, an organization schema, a web manifest, and the temporary D’THIRD SVG monogram.

Set `NEXT_PUBLIC_SITE_URL` to the canonical HTTPS origin (for example, `https://your-domain.com`) in production. Vercel's production project URL is used automatically if the variable is unset. Set it explicitly when using a custom domain so canonical URLs, Open Graph URLs, and the sitemap use that domain.

Certificates are configured in `credentials` in `lib/site-config.js`. Add only verifiable records, with `title`, `issuer`, `year`, and an optional public `href`.

## Images

- The official portrait is `public/images/dthird-profile.webp`; its source `Third-profile.jpg` remains at the project root.
- The cinematic cover is a separate, typographic placeholder. Set `coverImage.desktop` and optionally `coverImage.mobile` in `lib/site-config.js` to `.webp` image paths under `public/images/`, such as `/images/cover-desktop.webp` and `/images/cover-mobile.webp`.
- The cover uses a responsive `<picture>` source and `object-fit: cover`. Adjust its focal point in `app/globals.css` if needed.
- Add full-color WebP portfolio photographs to `public/images/` and list them in `portfolioItems` in `lib/site-config.js`. The work images reveal from monochrome to color as they enter view. The portrait stays monochromatic.
- Next Image Optimization is configured to emit WebP.

## Project inquiries

Define `NEXT_PUBLIC_CONTACT_EMAIL` in the Vercel project environment settings. The form prepares a message in the visitor’s email app. It does not use a server-side form endpoint.

## Deploy to Vercel

Import the repository in Vercel and keep the project root as the Root Directory. Vercel detects Next.js and uses the standard install and build scripts. Add `NEXT_PUBLIC_SITE_URL` and `NEXT_PUBLIC_CONTACT_EMAIL` to the project environment variables before deploying.

## Security notes

The inquiry form opens the visitor's mail app; the site does not accept or store form submissions. Global response headers reduce framing and MIME-sniffing risks. Keep `.env` files private and use Vercel's environment-variable settings for deployment.
